# Culinary guild UI preview

Captured from the local mock preview for [PR #114](https://github.com/Elevator-Robot/arcane.kitchen/pull/114) on November 10, 2026.

- Fictional Rowan/admin account and demo recipes; the preview strip remains visible.
- Chromium, light color scheme, reduced motion, and 1× pixel density.
- Desktop viewport: 1440 × 1000. Mobile viewport: 390 × 844.
- The desktop profile shows the expanded chef note; mobile shows its default collapsed state.
- The editor shows an existing demo recipe. Screenshots capture the visible viewport.
